# pomodoro

Persian-first Pomodoro app (Next.js App Router, React, TypeScript, Tailwind CSS).

See `AGENTS.md` and `docs/`. Package manager: pnpm only.

## Commands

- `pnpm install`
- `pnpm dev`
- `pnpm build`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm test:watch`
- `pnpm check` (lint + typecheck + test)
